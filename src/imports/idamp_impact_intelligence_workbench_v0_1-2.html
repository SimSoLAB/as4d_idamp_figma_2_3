Production architecture — working design

First-party by design.

Vendor-neutral architecture. The design does not select hosting, analytics vendors, consent tooling or identity providers.

Data path

bounded v0.1 architecture
v90 Experience

Controlled sections, proof media, blade states, system nodes and explicit actions.

→

Normalizes events into versioned schema + semantic tags.

→
First-Party Collector

Server-facing ingestion endpoint on controlled domain.

→
Raw Event Store

Append-only observation layer; interpretation never overwrites raw facts.

→
Sequence Engine

Reconstructs sessions, ordered journeys and derived observation classes.

→
Workbench

Journeys, themes, hypotheses, explicit actions and data-quality review.

Separate identity store

Person-level identity is not required for journey intelligence. A person record appears only after voluntary explicit submission and is linked with a recorded reason.

Interpretation layer stays reversible

Raw events remain stable. Theme mapping, sequence rules and hypothesis interpretations can evolve without rewriting historical observations.

Measurement validity

Know when not to conclude.

Data quality is a first-class surface. Sequence intelligence is useful only when delivery, ordering, visibility and identity-link coverage are understood.
