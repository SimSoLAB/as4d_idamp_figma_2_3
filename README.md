# as4d_figma_gpt_idamp.repair_layer

Controlled iDAMP.repair working-system source.

The repository began as a Figma Make export. The controlled implementation keeps that visual basis as a reference while governing behavior, claims, measurement and acceptance in code.

## Branch model

- `main`: accepted baseline
- `integration/working-system-build`: bounded working-system implementation candidate

## Commands

```bash
pnpm install --frozen-lockfile
pnpm typecheck
pnpm test
pnpm build
pnpm dev
```

See `ARCHITECTURE.md` and `ACCEPTANCE.md`.
