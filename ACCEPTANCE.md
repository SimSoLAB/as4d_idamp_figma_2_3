# Working System Acceptance

The workpackage is accepted as **working-system** only when all of the following are evidenced on the same commit:

- frozen dependency install PASS
- TypeScript typecheck PASS
- semantic-contract and negative tests PASS
- production build PASS
- browser runtime smoke PASS
- all seven route steps render
- desktop and mobile viewport smoke PASS without material horizontal overflow
- reduced-motion preference is honored for animated experience surfaces
- whitepaper form controls retain explicit labels and keyboard focusability
- semantic events are emitted from the actual UI runtime
- duplicate collapse precedes sequence assignment
- journey reconstruction preserves sequence integrity
- passive stages never count as proof of explicit action
- whitepaper request is gated by successful validation and does not imply backend delivery
- governed hero timing remains 5200 ms
- Impact Intelligence reads the same live session-event store
- CI reproduces the above state

Production deployment, production measurement, privacy/legal approval, consent, analytics vendor selection and external publication remain outside this acceptance.
